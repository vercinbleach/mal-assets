# Recursos de la lista de Vercin

Fondo de Giorno con llegadas de flores, corrientes de pétalos y parpadeo sutil.

- Vista previa: https://vercinbleach.github.io/mal-assets/
- SVG para MAL: https://vercinbleach.github.io/mal-assets/giorno-viento-mal.svg
- CSS de integración: [MAL-INTEGRACION.css](MAL-INTEGRACION.css)

El SVG es autónomo y no contiene JavaScript. La variante para MAL debe usarse con el CSS de integración: la preferencia de reducir movimiento la controla la página, que conserva su fondo estático original cuando se solicita reducir movimiento.

Añadir el contenido de `MAL-INTEGRACION.css` al final del tema actual. No sustituye el resto del diseño Liquid Glass. El archivo se sirve directamente como SVG, sin convertirlo a otra imagen.

La página de este repositorio es una vista previa independiente. Actualizar estos archivos no guarda cambios automáticamente en el perfil de MyAnimeList.

Composición y animación: Vincenzo Rosciano. El personaje de Giorno Giovanna y la ilustración original pertenecen a sus respectivos titulares. Proyecto personal, sin afiliación con MyAnimeList.
